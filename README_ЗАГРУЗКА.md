# Финальная версия лендинга Артёма Перлова

## Что сделано
- Все блоки перевёрстаны в HTML/CSS, а не вставлены одной картинкой.
- Шрифты: Cormorant Garamond для крупных заголовков, названий услуг, этапов и цитат; Onest для основного текста, кнопок, формы и контактов.
- Адаптивная версия для компьютера, планшета и телефона.
- Карточки услуг заполняют форму выбранной услугой и прокручивают к контактам.
- Форма настроена на одновременную отправку в Telegram и на email через Netlify Function.
- Добавлены политика конфиденциальности, sitemap, robots.txt и защитные заголовки.

## Что загрузить в GitHub
Заменить содержимое репозитория файлами и папками из этого архива. Важно загрузить папки `assets` и `netlify` целиком.

## Переменные Netlify
Открыть: Project configuration → Environment variables и добавить:

- `TELEGRAM_BOT_TOKEN` — токен бота
- `TELEGRAM_CHAT_ID` — ваш chat ID
- `SMTP_HOST` — `smtp.mail.ru`
- `SMTP_PORT` — `465`
- `SMTP_USER` — `a_perlov@mail.ru`
- `SMTP_PASS` — пароль внешнего приложения Mail.ru
- `LEAD_EMAIL_TO` — `a_perlov@mail.ru`

После сохранения переменных открыть Deploys → Trigger deploy → Deploy site.

## Проверка формы
1. Открыть сайт в режиме инкогнито.
2. Заполнить имя, телефон и задачу.
3. Поставить галочку согласия.
4. Отправить форму.
5. Проверить сообщение в Telegram и письмо на почте.
